# 🇪🇸 Онлайн-школа испанского языка

Полноценная веб-платформа для изучения испанского языка с 300 уроками от уровня A1 до C2.

## 🚀 Возможности

- **300 уроков** по всем уровням CEFR (A1, A2, B1, B2, C1, C2)
- **Интерактивные упражнения** и тесты
- **Система прогресса** для отслеживания обучения
- **Подписки** (бесплатная, базовая, премиум)
- **Аутентификация** через Firebase
- **Админ-панель** для управления контентом
- **Фиктивная система оплаты** для демонстрации
- **Юридические документы** (политика конфиденциальности, условия использования)

## 🛠 Технологический стек

- **Frontend**: React 18 + TypeScript + Vite
- **Стилизация**: Tailwind CSS
- **Маршрутизация**: React Router v6
- **Состояние**: Zustand
- **Backend**: Firebase (Authentication + Firestore)
- **Деплой**: GitHub Pages
- **CI/CD**: GitHub Actions

## 🎓 Уровни обучения

| Уровень | Название | Уроков |
|---------|----------|--------|
| **A1** | Начальный | 50 |
| **A2** | Элементарный | 50 |
| **B1** | Средний | 50 |
| **B2** | Продвинутый средний | 50 |
| **C1** | Продвинутый | 50 |
| **C2** | Владение в совершенстве | 50 |

## 💳 Тарифные планы

- **Бесплатный**: Первые 5 уроков каждого уровня
- **Базовый** (1 990₽/мес): Полный доступ к A1-A2
- **Премиум** (3 990₽/мес): Все уровни A1-C2

## 🔧 Установка

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/psychic-fortnight.git
cd psychic-fortnight/spanish-school

# Установить зависимости
npm install

# Настроить Firebase (см. .env.example)
cp .env.example .env
# Заполните .env своими данными Firebase

# Запустить в dev режиме
npm run dev

# Собрать для production
npm run build
```

## 🚀 Деплой на GitHub Pages

1. Настройте Firebase Secrets в GitHub
2. Push в main или ветку claude/*
3. GitHub Actions автоматически задеплоит проект
